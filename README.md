# House Sales Data Analysis and Visualization

## Project Overview

This project analyzes house sales data to understand pricing patterns and sales trends using Python and Pandas.

## Technologies Used

* Python
* Pandas
* Matplotlib
* NumPy

## Dataset

The dataset contains **4,600 house sales records** with **18 columns**, covering house sales from **May to July 2014** in King County, Washington.

## Key Analysis

* House prices based on bedrooms and bathrooms
* House sales by month and day
* House sales based on condition and floors
* Waterfront and non-waterfront house analysis
* City-wise house sales and prices
* Relationship between living area and house price

## Visualization

Different charts were created using Matplotlib to understand the data clearly and identify sales and pricing patterns.

## Conclusion

The project helped identify important patterns in house sales and understand how different features influence house prices.
